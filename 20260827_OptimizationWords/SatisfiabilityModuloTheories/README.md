解説:

Moduloというのがややこしいが、剰余の意味ではなく、理論を考慮した充足可能性判定くらいの意味か。
真偽のみを扱うSATに比べて、整数や実数なども扱えるSMTは表現能力が高い。
Leanなどの定理証明支援系と比べると、表現能力は劣るが、探索能力は高い。
