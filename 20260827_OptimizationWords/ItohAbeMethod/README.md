解説:

勾配流などの文脈に近い。
考えている問題設定はZeroth Order Methodsに近いが、発想はかなり異なる。
もし次の反復点が見つかれば、それは絶対に関数値が減少している。
しかし、その次の反復点を見つけるのが、$n$ 個の等式を解くことを要求するので難しい。
あまり理解できていないが、Zeroth Order Methodsよりも優れている場合もありそう。
